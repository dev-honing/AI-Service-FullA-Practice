# AI-Service-FullA-Practice

## 개인 학습 목표

### 현재 상태
- **AI 활용 경험**: 바이브 코딩(Vibe Coding) 방식으로 웹앱 다수 제작 — 프롬프트로 결과물을 만들어본 경험은 있으나, 내부 동작 원리는 이해가 부족한 상태
- **개발 환경**: Docker, Dev Container, Ollama 등 로컬 AI 개발 환경 구축 경험 전무 — 이번 과정에서 처음 접함
- **AI 이론/개념**: LLM, 토큰, 임베딩, 파인튜닝 등 기본 용어와 개념에 대한 체계적인 학습 필요
- **API 연동**: OpenAI/Anthropic 등 AI 모델 API를 직접 호출하고 서비스에 연동해본 경험 없음

### 14주 뒤 만들고 싶은 것
- **기술적으로**: AI API를 활용해 프론트엔드~백엔드까지 직접 설계·배포할 수 있는 역량 확보
- **결과물로**: 실사용 가능한 수준의 개인 프로젝트 1개 완성 (포트폴리오에 올릴 수 있는 수준)
- **역량 측면**: "AI가 짜준 코드를 그대로 쓰는" 단계에서 "왜 이렇게 동작하는지 설명할 수 있는" 단계로 성장

### 학습 방식 및 우선순위
- **이론 vs 실습**: 개념은 최소한으로 짚고, 직접 만들어보며 체득하는 방식 우선
- **기록 습관**: 매주 배운 내용/막힌 점을 README 또는 별도 로그에 짧게라도 기록
- **시간 배분**: 평일 위주로 학습, 주말은 밀린 실습 보충용으로 활용 (예시 — 실제 일정에 맞게 수정)
- **우선순위 원칙**: 완벽하게 이해하고 넘어가기보다, 일단 동작하는 것을 만들고 이후 원리를 복습

### 예상되는 어려움과 대비 전략
- **환경 설정 이슈**: Docker/Dev Container 관련 오류 예상 — 발생 시 공식 문서 먼저 확인 후 Discord 질문
- **개념 이해 부족**: AI 기본 용어가 익숙하지 않아 초반 진도가 느릴 수 있음 — 별도로 용어 정리 노트 운영
- **학습 페이스 관리**: 바이브 코딩에 익숙해져 있어 "이해 없이 진행"하는 습관이 나올 수 있음 — 매주 최소 1개 핵심코드는 직접 설명해보는 방식으로 점검
